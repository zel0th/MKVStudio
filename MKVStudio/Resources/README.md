# MKVStudio

Нативный интерфейс macOS для консольных утилит mkvmerge, mkvinfo, mkvextract и mkvpropedit.

Сборка, склейка, разбиение, главы, HDR-метаданные, вложения и очередь обрабатываются через отдельные процессы. Исполняемые файлы каждой утилиты задаются в настройках; графическое приложение не требуется.

Полное описание и результаты проверок находятся в README.md и Docs/performance-0.3.0.md в корне проекта.
