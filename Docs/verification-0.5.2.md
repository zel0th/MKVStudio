# Проверка MKVStudio 0.5.2

23 октября 2026. Apple Silicon, macOS 27.0.1. Версия 0.5.2, build 8.

## Поведение

После успешной публикации результата рабочий проект сбрасывается целиком: исходные файлы и свойства дорожек, название контейнера, путь результата, теги, главы, вложения, режим склейки и параметры разбиения. Сбрасываются также выбранные дорожки/главы, кэш тегов, предпросмотр и сведения о контейнере. Исходники, результаты на диске, сохранённые проекты, настройки и история очереди не удаляются. Открытый раздел остаётся прежним, поэтому в очереди виден завершённый результат.

При постановке задания в очередь запоминаются его рабочий проект и поколение сессии. Завершение очищает только соответствующий, не изменённый после постановки проект. Начатый импорт нового файла, новые правки и новая сессия защищены от очистки старым заданием. Простое чтение тегов без правок не мешает сбросу. Эта связь существует только в текущей сессии и не меняет формат сохранённой очереди.

Результат с предупреждением очищает проект после успешного сохранения. Ошибка, отмена и конфликт пути результата оставляют поля для исправления и повторной попытки. Запоздавшие ответы чтения глав и информации не могут заполнить уже очищенный проект или сбросить индикатор более нового чтения.

## Проверки

- Новая проверка до исправления воспроизвела сохранение старых полей после завершённой сборки.
- После исправления прошли [33 сценария](integration-0.5.2.txt) через `python3 Scripts/check-engine.py`. Проверочные тела Swift Testing выполнялись отдельным исполняемым файлом из-за отсутствия модуля Testing в установленном Command Line Tools.
- Настоящие консольные утилиты проверили полный сброс после сборки, склейки, разбиения, изменения заголовков и извлечения. После каждой операции повторный импорт проверял новые название/путь результата, пустые правки тегов, отсутствие старых глав и вложений. Исходник остался побайтово прежним.
- Управляемые дочерние процессы проверили предупреждение, ошибку, отмену, конфликт при публикации, несколько заданий, изменение проекта во время обработки, новую сессию, начатый импорт и отложенные ответы чтения. Синхронизация выполнялась по сигналам готовности, а не предположению о длительности обработки.
- В отдельном QA-приложении с производственными представлениями заполнены название контейнера, TITLE, DATE_RELEASED и глава. После сборки окно показало «Готово», список исходников очистился. Проверены пустые редакторы тегов и глав, вложения, параметры разбиения, сведения о контейнере и строка результата. Затем через стандартный диалог импортирован другой проверочный MP4: прежние название, теги и год отсутствовали, имя результата было предложено заново.
- Release-сборка, проверка Info.plist, проекта Xcode и `git diff --check` успешны. QA-копия подписана во временном каталоге, чтобы исключить служебные атрибуты iCloud при подписании тестового пакета.
- DMG прошёл `hdiutil verify` и открыт только для чтения. PKG внутри совпал с отдельным установщиком; после распаковки проверены подпись приложения, версия/build и хеши всех файлов пакета относительно release-сборки. ZIP прошёл проверку целостности и совпадения файлов. Системная установка пользователя при проверке не менялась.
