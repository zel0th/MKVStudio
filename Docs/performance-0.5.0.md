# Нагрузка MKVStudio 0.5.0

20 октября 2026. Apple M4, 10 ядер, 24 ГиБ, macOS 27.0.1, Swift 6, оптимизированная сборка. CPU указан относительно одного ядра; 100% означает одно занятое ядро. RSS — резидентная память процесса. WindowServer, службы Keychain и прочие процессы macOS в эти значения не входят.

## Интерфейс SwiftUI

Измерение `Scripts/sample-ui.py`, интервал около 50 мс. Для сценария поиска использовано отдельное приложение `MKVStudio-QA.app`: производственные представления, модель состояния и обработка MKV, но фиксированные ответы сервиса и тестовая обложка. Оно собирается через `Scripts/build-ui-harness.py` и не входит в дистрибутив. Этот замер не характеризует задержку внешнего API.

| Сценарий | Длительность | Средний CPU | Пиковая RSS |
|---|---:|---:|---:|
| Основная сборка, открытые настройки без действий | 19,90 с | 0,60% | 134,77 МиБ |
| QA: поиск, выбор полей, предпросмотр, перенос и сборка | 36,14 с | 7,42% | 212,70 МиБ |
| QA: окно после переноса, включая наблюдение интерфейса | 154,63 с | 2,16% | 211,86 МиБ |

В последнем интервале RSS закончилась на 203,08 МиБ против 203,42 МиБ в начале. Кратковременный максимум CPU при работе с интерфейсом — 117,95% на интервале около 50 мс. Это не постоянная нагрузка. Предварительный интервал QA с навигацией и открытием окна не считается простоем, хотя в сыром файле имеет техническую метку `idle`.

[Сводка измерений](ui-summary-0.5.0.json). Сырые CSV находятся локально в `build/ui-performance-0.5.0.csv` и `build/ui-production-idle-0.5.0.csv`.

## Повторная обработка метаданных

`Scripts/benchmark-metadata.py`: три серии по 100 циклов поиска, чтения карточки/участников и декодирования постера. Фикстура содержит 20 результатов, 300 участников и длинное описание. Запросов к внешнему сервису в этом тесте нет.

| Серия | Циклы | CPU, с | Время, с | Пиковая RSS |
|---|---:|---:|---:|---:|
| 1 | 100 | 0,5635 | 0,5670 | 46,14 МиБ |
| 2 | 100 | 0,5321 | 0,5330 | 46,33 МиБ |
| 3 | 100 | 0,5251 | 0,5255 | 46,34 МиБ |

Средняя стоимость — около 5,4 мс CPU на цикл. Плотный цикл на это короткое время занимает примерно одно ядро. После серии: 46,30 МиБ RSS и 0,0068% CPU за 5,31 с простоя. Рост пиков между первой и третьей сериями — 0,20 МиБ; в этой серии не наблюдался неограниченный рост памяти. Это отдельный процесс без SwiftUI, его память нельзя выдавать за память всего приложения.

`Scripts/benchmark.py`: настоящий `AppState` без интерфейса, синтетический PCM-файл 1 ГиБ, 12 последовательных заданий: по четыре сборки, склейки двух входов и разбиения по 256 МиБ. Каждое задание записывает стандартные теги. Все задания завершились успешно.

## Изменения для ограничения нагрузки

- Поля карточки готовятся один раз, а не заново при каждом обновлении SwiftUI.
- Декодированная миниатюра сохраняется в модели; повторного декодирования для её показа нет. Максимальная сторона — 480 пикселей.
- JSON ограничен 2 МиБ, изображение — 8 МиБ и 80 мегапикселями. Лимиты проверяются при получении заголовков и каждого блока данных.
- Отмена и закрытие окна прерывают сетевую операцию. Старый ответ не заменяет результаты нового запроса.
- Сетевые сессии не сохраняют кэш, cookies и учётные данные. После завершения буферы освобождаются.

Замеры — ограниченные воспроизводимые сценарии, а не доказательство отсутствия всех возможных утечек или оценка суммарной нагрузки системы. Живой API отдельно проверен с пользовательским ключом: поиск, русские поля и JPEG-постер успешно получены; [результат без ключа](live-api-0.5.0.json).
