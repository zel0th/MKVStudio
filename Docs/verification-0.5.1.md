# Проверка MKVStudio 0.5.1

23 октября 2026. Apple Silicon, macOS 27.0.1. Версия приложения 0.5.1, build 7.

## Причина и исправление

Когда в MKV нет элемента Tags, mkvextract успешно завершается с кодом 0 и пустым выводом. Приложение передавало этот вывод XML-парсеру, который выдавал `zero length data`. В поиске информации чтение существующих тегов происходит перед показом карточки, поэтому пользователь видел результаты поиска, но не мог выбрать поля для переноса.

На границе успешного извлечения пустой вывод теперь преобразуется в пустой документ `<Tags/>`. Ошибки команды, непустой повреждённый XML и неверный корневой элемент не игнорируются. Общий XML-парсер остаётся строгим. Сетевой клиент и работа с ключом API не менялись.

## Проверки

- Ошибка воспроизведена на временном MKV: теги удалены через mkvpropedit, mkvextract вернул код 0 и 0 байт. Новая регрессионная проверка до исправления завершилась с исходной ошибкой `zero length data`.
- После исправления прошли [29 функциональных сценариев](integration-0.5.1.txt) через `python3 Scripts/check-engine.py`. Использованы настоящие mkvmerge, mkvextract, mkvinfo и mkvpropedit. На этой машине проверочные тела Swift Testing выполняются отдельным исполняемым файлом, поскольку Command Line Tools не содержат модуль Testing.
- Два новых сценария покрывают MKV без Tags: загрузку редактора, предпросмотр XML, первую запись тегов в файл без Tags, выбор карточки, перенос выбранных полей, очередь и сборку результата. Извлечённые дорожки и исходники сравнены побайтово. Отдельно проверены ошибка извлечения отсутствующего файла и отклонение некорректного XML.
- Через отдельное QA-окно с производственными представлениями и фиксированными ответами API открыт MKV без Tags. Поиск, выбор карточки и перенос пяти полей завершились без ошибки. Сборка в интерфейсе показала «Готово». Повторное извлечение подтвердило TITLE, DATE_RELEASED, DIRECTOR, GENRE и SUMMARY на русском; снятые с выбора ACTOR и DESCRIPTION отсутствовали. Видеопоток результата совпал побайтово с исходным.
- Это проверка воспроизведённого случая на тестовом файле. Исходный фильм пользователя и настоящий внешний API в этой версии повторно не проверялись; тестовая загрузка постера использовала фиксированный ответ.
- После завершения операции выполнен отдельный 20-секундный [замер покоя QA-окна](ui-idle-summary-0.5.1.json): 367 отсчётов, средний CPU 0,55% одного ядра, RSS с 183,4 до 151,8 МиБ, наблюдаемый максимум 184,0 МиБ. Это короткий замер после операции, не нагрузочный тест больших файлов и не доказательство отсутствия всех утечек. Полные предыдущие замеры версии 0.5.0 сохранены отдельно.
- Release-сборка успешна. Info.plist, проект Xcode и `git diff --check` прошли проверку.
- DMG прошёл `hdiutil verify`, смонтирован только для чтения. PKG внутри совпал с отдельным PKG побайтово и распакован через `pkgutil --expand-full`. Проверена подпись вложенного приложения и хеши всех четырёх файлов его пакета относительно release-сборки. ZIP прошёл проверку целостности, его файлы приложения также совпали. Установочные скрипты не менялись; системная установка в ходе проверки не выполнялась.
