# Проверка автономного дистрибутива 0.6.0

Дата: 23 октября 2026 года. Версия 0.6.0, сборка 9; Apple Silicon, macOS 14+. Локальная проверка выполнена на macOS 27.0.1 с Command Line Tools.

## Состав и установка

DMG содержит `MKVStudio.app`, ссылку «Программы» на `/Applications` и инструкцию. PKG отсутствует. Для установки достаточно скопировать приложение и извлечь образ. Homebrew, установка команд в системные каталоги и загрузка компонентов при первом запуске не требуются.

В `Contents/Helpers/ConsoleTools` находятся `mkvmerge`, `mkvinfo`, `mkvextract`, `mkvpropedit` 102.0 и единственная необходимая несистемная динамическая библиотека `libs/libQt6Core.6.dylib` 6.11.1. Рекурсивные зависимости и фактические пути загрузки проверены. Графическое приложение поставщика, плагины и неиспользуемые библиотеки не включены. Лицензии, документация и соответствующие архивы исходников находятся в `Contents/Resources/ConsoleTools`.

## Выполненные проверки

- Релизная сборка и ZIP созданы из текущих исходников. Проверены архитектура arm64, контрольные суммы вложенных программ и подписи всех уровней.
- Все четыре команды запускаются с чистым окружением и загружают Qt Core из приложения. В интеграционных тестах, нагрузочной серии и ручной проверке интерфейса дополнительно запрещено чтение внешних установок утилит.
- Все **35 интеграционных сценариев** прошли: [протокол](integration-0.6.0.txt). В том числе побайтовое сохранение потоков и вложений, склейка, разбиение, главы, HDR, теги, очередь, отмена, защита исходников, очистка рабочего проекта и импорт метаданных по фиксированным ответам API.
- Проверены приоритет встроенных программ, явный выбор внешних версий, ошибки отсутствующих компонентов и перенос сохранённых заданий между расположениями приложения, включая инструменты записи тегов.
- В обычном интерфейсе релизной копии импортирован `Samples/Видео.mp4`, задано название контейнера «Автономный тест 0.6.0», записаны TITLE «Проверка встроенных утилит» и DATE_RELEASED `2026`. Очередь показала завершение; список исходников очистился. В результате подтверждены название и теги, извлечённый видеопоток совпал побайтово, исходный MP4 не изменён.
- В настройках видны все четыре пути внутри приложения; переключение «Использовать встроенные» работает. Тестовая копия использует отдельный идентификатор настроек. Её исполняемый код совпадает с релизом побайтово после удаления подписей, различающихся из-за идентификатора.
- Проверены контрольная сумма DMG, его состав, отсутствие PKG, ссылка «Программы», копирование в другой каталог с пробелами и кириллицей. Образ извлечён **до** запуска команд из скопированного приложения.
- Содержимое приложения в DMG, ZIP и каталоге релизной сборки совпадает побайтово. Проверена целостность ZIP и SHA-256 архивов исходников. Намеренная порча тестовой копии `mkvinfo` обнаружена проверкой; после восстановления файла проверка снова прошла.
- Нагрузочная серия из 12 заданий и замер интерфейса завершены: [отчёт](performance-0.6.0.md).

Дистрибутив проверяется командой `python3 Scripts/test-dmg.py build/MKVStudio-0.6.0-macOS-arm64.dmg`.

## Границы проверки

Полный Xcode и удалённый CI не запускались. В установленном Command Line Tools отсутствует модуль Swift Testing; `Scripts/check-engine.py` компилирует и выполняет те же тестовые сценарии с обычными проверочными функциями. Проект Xcode и шаблон CI обновлены для встраивания утилит, но отдельно не проверены сборкой Xcode.

Сборка подписана локально (ad-hoc), без Developer ID и нотарификации Apple. Проверка структуры и локального запуска не означает подтверждение Gatekeeper для загруженного из интернета приложения. Системная защита не отключалась.

Живой сервис поиска фильмов в этой работе повторно не проверялся: изменения касаются упаковки и поиска исполняемых файлов. API-ключи не использовались. Установленное пользовательское приложение, его настройки и системные утилиты не изменялись.
