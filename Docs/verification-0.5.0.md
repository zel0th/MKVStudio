# Проверка MKVStudio 0.5.0

20 октября 2026. Apple Silicon, macOS 27.0.1, консольные утилиты 102.0.

- Release-сборка успешно собрана: версия 0.5.0, build 6. Info.plist и Xcode project прошли проверку plist.
- [27 функциональных сценариев](integration-0.5.0.txt) прошли с настоящими mkvmerge, mkvextract, mkvinfo и mkvpropedit. На этой машине Command Line Tools не содержат модуль Swift Testing, поэтому `Scripts/check-engine.py` выполняет те же тела проверок в отдельном исполняемом файле.
- Новые проверки покрывают поиск по названию/году/ID/ссылке, русские поля, фильтрацию участников, обработку 401/402/403/404/429, неверный JSON, повреждённое/слишком большое изображение и отмену.
- Локальный HTTP-сервер проверяет настоящий сетевой транспорт: обычный ответ, превышение лимита в заголовках и в потоке, запрет перенаправления запроса с ключом и отмену незавершённой загрузки.
- Выбор тегов, режим заполнения пустых полей, название контейнера, постер, сохранение/открытие проекта и снимок очереди проверены сборкой настоящего MKV. Извлечённый постер совпал побайтно, аудио/субтитры не изменились, исходник сохранился.
- Ошибка загрузки постера и устаревшая рабочая сессия не оставляют частичных изменений проекта. Сброс правок возвращает исходные значения. Теги всего сериала уровня 70 не заменяют теги эпизода уровня 50.
- В отдельной QA-сборке с производственными представлениями проверены поиск, список результатов, предпросмотр, снятие двух флажков, добавление постера и сборка через окно приложения. Повторное чтение результата подтвердило ровно пять выбранных полей: TITLE, DATE_RELEASED, DIRECTOR, GENRE, SUMMARY; ACTOR и DESCRIPTION отсутствовали. Название контейнера осталось прежним, вложение `cover.png` присутствовало.
- Сохранение, чтение, обновление и удаление ключа проверены в изолированной записи Связки ключей. Тестовая запись удалена.
- С предоставленным пользователем ключом отдельно выполнен запрос настоящего сервиса производственным `KinopoiskClient` / `BoundedHTTP`: поиск «Матрица», 1999 год, карточка ID 301, участники и JPEG-постер. Все этапы успешны. [Отчёт](live-api-0.5.0.json) не содержит ключа.
- Ключ сохранён в Связке ключей для MKVStudio. Из-за прекращения связи с инструментом управления окнами финальная проверка с настоящим сервисом выполнена сетевым кодом приложения отдельно, а не повторным проходом через окно поиска. Проверка интерфейса до этого выполнена с фиксированными ответами.
- [Замеры нагрузки](performance-0.5.0.md): интерфейс, 300 циклов метаданных и 12 операций с файлом 1 ГиБ. После оптимизации повторной подготовки полей и миниатюры функциональные проверки и нагрузочные серии выполнены заново.
- DMG прошёл `hdiutil verify`. PKG распакован через `pkgutil --expand-full`; подпись вложенного приложения проверена, исполняемый файл совпал побайтно с release-сборкой. ZIP прошёл проверку целостности.
- Пять сценариев установки четырёх консольных утилит повторно выполнены в изолированных каталогах: чистая/частичная установка, повторный запуск, повреждённый архив и конфликты ссылок. Системная установка пользователя не менялась. [Результат](installer-0.5.0.txt).
