# Нагрузка автономной версии 0.6.0

Проверено 23 октября 2026 года на macOS 27.0.1, Apple Silicon. Использованы встроенные утилиты 102.0. Чтение `/opt/homebrew`, `/usr/local` и прежнего системного каталога инструментов было запрещено тестовой песочницей; системные установки не изменялись.

## Приложение с интерфейсом

Проверена копия релизного приложения с отдельным идентификатором для изоляции настроек. Код исполняемого файла совпадает с релизом побайтово после удаления различающихся подписей. В копии через обычный интерфейс импортирован MP4, изменены название контейнера и теги, выполнена сборка MKV, открыты и закрыты настройки.

Затем без взаимодействия с окном выполнено 465 измерений за 24,95 секунды:

| Метрика | Результат |
| --- | ---: |
| Средняя загрузка CPU | 0,0077% одного логического ядра |
| RSS в начале | 168,56 МиБ |
| RSS в конце | 168,55 МиБ |
| Максимальная RSS | 168,56 МиБ |

Измерения: [ui-summary-0.6.0.json](ui-summary-0.6.0.json). Это простой открытого интерфейса после обработки, а не пик памяти при всех возможных действиях.

## Последовательная обработка

`Scripts/benchmark.py` создаёт синтетический PCM-файл 1 ГиБ и выполняет 12 заданий через настоящий `AppState`: четыре сборки, четыре склейки двух входов и четыре разбиения по 256 МиБ. Каждое задание также записывает стандартные теги. Все 12 завершились успешно. Результаты и временный исходник удаляются после теста.

| Процесс | CPU во время заданий | Максимальная RSS |
| --- | ---: | ---: |
| Обёртка с AppState, без SwiftUI | 0,74–1,92% | 14,13 МиБ |
| Консольные утилиты | 92,48–97,35% | 39,44 МиБ |

100% CPU означает одно логическое ядро, а не весь процессор. RSS опрашивалась примерно каждые 50 мс; краткие пики между выборками могли быть пропущены. Память обёртки и память интерфейса измерялись в разных процессах и сценариях, поэтому эти значения нельзя складывать как измеренный общий пик приложения.

После 12 заданий память обёртки составила 14,13 МиБ; за последующие 5,33 секунды простоя CPU составил 0,0069%. Память к концу серии стабилизировалась; непрерывного роста в этом тесте не обнаружено. Эти измерения не заменяют длительный тест на всех форматах и размерах файлов.

Полные результаты: [queue-benchmark-0.6.0.jsonl](queue-benchmark-0.6.0.jsonl).

Повода менять обработку ради нагрузки по этой серии не обнаружено: основная работа остаётся в консольных процессах, интерфейс не опрашивает их в простое. Архивы исходников внутри приложения занимают место на диске и не загружаются приложением в память.
