# MKVStudio 0.6.0

Нативная macOS-обёртка над **mkvmerge, mkvinfo, mkvextract и mkvpropedit** на SwiftUI. Обработка медиа выполняется внешними консольными утилитами. Приложение не декодирует и не перекодирует аудио и видео.

## Автономная версия 0.6.0

Откройте DMG и перетащите **MKVStudio.app** в **«Программы»**. Все четыре консольные утилиты и необходимые библиотеки находятся внутри приложения. PKG, Homebrew, права администратора для установки утилит и загрузка компонентов при первом запуске не требуются. Обработка медиа работает без интернета; поиск информации о фильмах использует сеть по запросу пользователя.

## Исправление 0.5.2

После успешного сохранения результата (включая результат с предупреждением) рабочий проект полностью очищается: исходники, название контейнера и путь результата, теги, главы, вложения, параметры склейки/разбиения и свойства дорожек. История очереди и настройки сохраняются. Ошибка, отмена или невозможность сохранить результат оставляют поля для повторной попытки. Если после постановки задания в очередь начата новая работа, завершение старого задания её не очищает. Запоздавшее чтение глав и информации не возвращает старые данные. [Проверка исправления и дистрибутива](Docs/verification-0.5.2.md).

## Исправление 0.5.1

Исправлена ошибка `zero length data` при выборе произведения для MKV без тегов: успешный пустой ответ mkvextract теперь означает отсутствие тегов. Работают открытие карточки, перенос выбранных полей, предпросмотр и первая запись тегов. Ошибки извлечения и повреждённый XML по-прежнему сообщаются пользователю. [Проверка исправления и дистрибутива](Docs/verification-0.5.1.md).

## Возможности

- **Сборка:** импорт видео, аудио и субтитров, перетаскивание из Finder, чтение дорожек через `mkvmerge -J`. Выбор, порядок, названия, языки, default/forced и задержка дорожек.
- **Склейка:** последовательное соединение файлов с явным сопоставлением дорожек через `--append-to` и `--append-mode file`. Порядок файлов меняется кнопками. Выбранные дорожки должны иметь одинаковый состав, порядок, кодеки и параметры. Окончательную совместимость проверяет mkvmerge. Имена и цветовые параметры результата берутся из первого файла.
- **Разбиение:** по размеру, длительности, отметкам времени, главам или диапазонам. Диапазоны с `+` соединяются в одну часть. Есть ограничение числа файлов и связывание сегментов. Результат — новая папка `имя.parts`, файлы `part-001.mkv` и далее; один выбранный фрагмент может называться `part.mkv`. Разрезы привязаны к ключевым кадрам, поэтому время и размер приблизительные.
- **Визуальные главы:** таблица, временная шкала, ползунок начала, имя, язык, начало/конец, добавление и удаление глав, вложенные главы, порядок и несколько редакций. Импорт XML/простого текста, чтение из MKV через mkvextract, экспорт XML. Сохраняются UID, флаги, дополнительные названия и прочие нетронутые XML-элементы. Главы редактора заменяют главы исходников при сборке. Сортировка глав не выполняется автоматически: порядок редакции, в том числе ordered editions, сохраняется.
- **Цвет и HDR:** PQ/HLG, основные цвета, матрица, диапазон, число бит, MaxCLL/MaxFALL, координаты RGB и белой точки, минимальная/максимальная яркость мастеринга. Пустое поле сохраняет исходное значение. Это правка метаданных контейнера, не преобразование SDR в HDR, не изменение битности кодека и не создание динамических метаданных Dolby Vision/HDR10+.
- **Редактор тегов:** название контейнера и 13 стандартных полей Matroska: TITLE, SUBTITLE, DATE_RELEASED, RECORDING_LOCATION, DIRECTOR, ACTOR, SCREENPLAY_BY, PRODUCER, COMPOSER, GENRE, SUMMARY, DESCRIPTION, COMMENT. Даты проверяются по календарю; страна задаётся кодом, например JP. RECORDING_LOCATION означает страну / место съёмки.
- **Вложения:** обложки, шрифты, выбор существующих вложений; сохранение тегов и исходных глав. Нативный Quick Look показывает изображения, XML, текст и другие поддерживаемые macOS форматы. Встроенные вложения извлекаются через mkvextract в уникальную временную папку, которая удаляется после закрытия просмотра. Лимит вложения — 50 МБ, XML тегов — 2 МБ. Для неизвестных форматов Quick Look может показывать только сведения о файле.
- **Очередь:** снимки параметров, XML глав и правок тегов, последовательная обработка, прогресс, отмена, ограниченный журнал, открытие результата в Finder. Ожидающие задания после перезапуска запускаются вручную.
- **Извлечение:** выбранная дорожка через mkvextract, включая сопутствующие файлы VobSub.
- **Информация:** структура контейнера через mkvinfo.
- **Заголовки:** названия, языки и флаги через mkvpropedit в отдельной копии. Состав дорожек, задержки и HDR в этом действии не меняются; для них используется сборка.
- **Проекты:** явное сохранение и открытие файлов `.mkvstudio` с фильтром по расширению; проекты версии 0.1 продолжают открываться. При запуске рабочая область пустая; очередь и настройки сохраняются. Светлая, тёмная и системная темы, нативные панели и сочетания клавиш.

- **Поиск информации:** Kinopoisk Unofficial API, личный ключ в Связке ключей, поиск по названию/году/ID/ссылке, выбор русских тегов и постера перед переносом.

## Запуск и инструменты

Основной дистрибутив — `build/MKVStudio-0.6.0-macOS-arm64.dmg`: приложение, ссылка «Программы» и краткая инструкция. ZIP содержит такое же автономное приложение. После копирования образ можно извлечь.

Требуются **Apple Silicon и macOS 14+**. Сборка имеет локальную ad-hoc подпись и пока не нотарифицирована Apple. Защиту macOS отключать не нужно.

Встроенный комплект: `mkvmerge`, `mkvinfo`, `mkvextract`, `mkvpropedit` версии 102.0 и Qt Core 6.11.1. Консольные программы запускаются как отдельные процессы из `Contents/Helpers/ConsoleTools`; MKVStudio не линкуется с ними. Проверяется рекурсивное дерево зависимостей: копируются только используемые библиотеки. Графическая программа поставщика и её плагины не входят в приложение.

По умолчанию выбираются встроенные утилиты. Сохраняется возможность явно выбрать другие версии в настройках; кнопка **«Использовать встроенные»** сбрасывает ручные пути. Повреждённый встроенный комплект не подменяется незаметно внешними инструментами. При переносе приложения сохранённые задания находят встроенные команды по новому расположению, включая инструменты записи тегов.

Системные каталоги и существующие установки утилит не изменяются. Для запуска программ из обычного Терминала по короткому имени по-прежнему нужна отдельная установка или собственная настройка PATH; MKVStudio она не нужна.

Справочники: [mkvmerge](https://man.archlinux.org/man/mkvmerge.1.en), [mkvextract](https://man.archlinux.org/man/mkvextract.1.en), [mkvinfo](https://man.archlinux.org/man/mkvinfo.1.en), [mkvpropedit](https://man.archlinux.org/man/mkvpropedit.1.en).

## Сохранность данных

Исходники не перезаписываются. Обработка идёт в уникальной временной папке рядом с назначением. Файл или папка с частями переносится на конечное место только при коде завершения 0 или 1 (предупреждение консольной утилиты). Существующий результат не заменяется, включая появление файла во время обработки. При отмене временные данные задания удаляются. После аварийного закрытия путь к оставшейся папке указан в журнале.

Утилиты запускаются через `Process` с массивом аргументов, без shell. Для Unicode-путей используется UTF-8. Проект и история хранятся локально; поиск информации и загрузка постера используют сеть по запросу пользователя. Большие медиафайлы не загружаются в память приложения.

## Проверки и сборка

```sh
bash Scripts/build-app.sh
bash Scripts/build-dmg.sh
MKVSTUDIO_TOOLS_DIRECTORY="$PWD/build/MKVStudio.app/Contents/Helpers/ConsoleTools" MKVSTUDIO_ISOLATE_TOOLS=1 python3 Scripts/check-engine.py
MKVSTUDIO_TOOLS_DIRECTORY="$PWD/build/MKVStudio.app/Contents/Helpers/ConsoleTools" MKVSTUDIO_ISOLATE_TOOLS=1 python3 Scripts/benchmark.py
```

Сборка загружает закреплённый образ утилит и архивы их исходников только на машине разработчика, сверяет SHA-256 и создаёт приложение, ZIP и SHA-256 в `build/`. Этот путь работает с Command Line Tools; полный Xcode не требуется. Проект `MKVStudio.xcodeproj` также обновлён. В полном Xcode тесты Swift Testing запускаются через `bash Scripts/test.sh`.

В установленном здесь Command Line Tools отсутствует модуль `Testing`. Скрипт `check-engine.py` выполняет те же **35 сценариев** из `Tests/EngineTests.swift` и `Tests/SessionTests.swift` и `Tests/MetadataTests.swift`, `Tests/KinopoiskTests.swift`, `Tests/BundledToolsTests.swift` с обычными проверочными функциями. Используются настоящие консольные утилиты. Проверяются потоки и вложения побайтово, склейка, все режимы разбиения, главы и вложенность, HDR, независимые пути инструментов, старые проекты, защита исходников/результата, Unicode, большой вывод и отмена.

`Scripts/benchmark.py` создаёт временный синтетический PCM-файл 1 ГиБ, выполняет 12 операций через настоящий `AppState` и удаляет результаты. Измеряет CPU отдельно для обёртки и утилит, RSS каждые 50 мс. Интерфейс измеряется отдельно через `Scripts/sample-ui.py`. Каждая операция также применяет стандартные теги к результату. Результаты автономной версии — в [отчёте о нагрузке](Docs/performance-0.6.0.md).

Шаблон GitHub Actions рассчитан на самостоятельно подключённый macOS ARM64 runner с Command Line Tools и Python 3. Он сначала собирает автономное приложение, затем проверяет его встроенные утилиты при запрете доступа к внешним установкам. Удалённый CI в рамках этой работы не запускался.

## Интерфейс 0.5.0

Боковая панель открывается с шириной 300 pt, инспектор — 380 pt (максимумы их диапазонов); разделители остаются изменяемыми. Во всех рабочих разделах используется общая широкая зелёная кнопка «Добавить в очередь». Красная кнопка «Убрать завершённые» закреплена внизу очереди и остаётся видимой при открытом журнале и пустом списке. Она очищает историю, не файлы результатов. Настройки занимают 740 × 670 pt и не содержат вертикальной прокрутки.

Стандартные `NavigationSplitView`, `Table`, `inspector`, системные кнопки, панели и материалы. Ориентир — [принципы Apple](https://developer.apple.com/design/human-interface-guidelines/design-principles).

## Проверка автономного дистрибутива

`python3 Scripts/verify-bundle.py /путь/MKVStudio.app` проверяет подписи, архитектуру, SHA-256 вложенных программ, замкнутость зависимостей и запуск всех четырёх команд с чистым окружением. `Scripts/check-engine.py` поддерживает `MKVSTUDIO_TOOLS_DIRECTORY` и тестовый запрет чтения Homebrew, `/usr/local` и прежнего системного каталога утилит (`MKVSTUDIO_ISOLATE_TOOLS=1`). Это не изменяет системные файлы.

Для итогового DMG проверяются контрольная сумма образа, отсутствие PKG, ссылка на `/Applications`, совпадение файлов приложения до и после копирования, запуск из нового пути с пробелами и кириллицей. `python3 Scripts/test-dmg.py build/MKVStudio-0.6.0-macOS-arm64.dmg` воспроизводит эти проверки. Протокол: [проверка 0.6.0](Docs/verification-0.6.0.md).

Источники и SHA-256 закреплены в `Distribution/console-tools.json`. В `Contents/Resources/ConsoleTools` находятся лицензии, сведения о происхождении, архивы исходников консольного комплекта и Qt Base. MIT относится только к собственному коду MKVStudio; отдельные программы сохраняют исходные лицензии. Системные установочные скрипты прежних версий удалены.

Удаление последнего исходника очищает название и путь результата. При завершении приложения рабочая сессия сбрасывается; сохранённые проекты и очередь остаются. Настройки открываются на дисплее основного окна. Диалоги выбора утилит открывают настроенный или обнаруженный каталог. Вспомогательный текст увеличен до системного основного размера. Проверка: [33 сценария](Docs/integration-0.5.2.txt).

## Как работают правки тегов

Редактор читает значения первого файла через mkvextract. Язык выбирается по первому стандартному тегу произведения; его можно сменить до внесения правок или после их сброса. Несколько актёров, режиссёров и жанров вводятся отдельными строками и сохраняются отдельными Simple-элементами. Описания сохраняют переносы строк внутри одного значения.

В очередь попадают только изменённые поля. После mkvmerge, пока результат ещё находится во временной папке, приложение читает его теги через mkvextract и применяет правки через mkvpropedit. Это сохраняет актуальные UID дорожек и глав после склейки и разбиения. Изменяются только общие теги выбранного уровня (50 — фильм/эпизод, 70 — сериал) и языка с флагом языка по умолчанию. Остальные уровни, переводы, привязки, неизвестные исходные поля и вложенные сведения сохраняются. При удалении конкретного поля удаляются и его вложенные сведения. Название контейнера задаётся отдельно через mkvmerge.

При разбиении правки применяются к каждой части. Если чтение или запись тегов не завершились успешно, результат не публикуется. XML-сущности отвергаются, внешние XML-ссылки не загружаются. Имена вложений не используются как пути извлечения. Сохранённые проекты и задания прошлых версий совместимы.

Красная кнопка **«Очистить»** над списком исходников очищает источники, название, место результата и связанные правки тегов. Очередь и файлы на диске сохраняются; отдельно добавленные вложения и отредактированные главы остаются в проекте.

Список редактируемых полей основан на [стандартных тегах Matroska](https://www.matroska.org/technical/tagging.html). Отдельного стандартного тега страны производства нет; поле RECORDING_LOCATION обозначает место съёмки и принимает код страны с необязательным регионом и городом.


## Поиск информации в Кинопоиске

В **Настройки → Поиск информации** введите личный ключ [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/) и нажмите **Сохранить ключ**. Ключ хранится в системной Связке ключей, не в настройках UserDefaults, проектах или журналах. Вкладки настроек помещаются без прокрутки.

В **Редакторе тегов → Найти информацию…** доступны поиск по названию и году, ID или ссылке на фильм/сериал. Запрос отправляется только после нажатия «Найти»; содержимое видео не отправляется. Выберите произведение и отметьте нужные поля. По умолчанию включено «Заполнять только пустые поля». Название контейнера выбирается отдельно. Импортируются только имеющиеся русские значения; автоматического перевода нет. Страны производства показаны для справки и не подменяют стандартное поле места съёмки.

Предпросмотр постера загружается при выборе произведения. Полное изображение скачивается только при отмеченном пункте **Добавить постер во вложения** и нажатии **Перенести выбранное**. Поддерживаются JPEG/PNG до 8 МБ и 80 мегапикселей; миниатюра ограничена 480 пикселями. Остальные вложения сохраняются. Скачанные постеры хранятся неизменяемыми файлами в `~/Library/Application Support/MKVStudio/ImportedPosters`, чтобы сохранённые проекты и очередь работали после перезапуска. Как и другие вложения проекта, эти файлы нужно сохранять, пока они используются.

Данные сериала записываются на стандартном уровне Matroska 70; теги отдельного эпизода уровня 50 сохраняются. Язык импортированных тегов — `ru`. Если уже есть несохранённые правки другого языка/уровня, сначала соберите результат либо сбросьте эти правки. Сам импорт меняет проект; запись в MKV выполняется при сборке через mkvmerge / mkvextract / mkvpropedit. Ошибка или отмена скачивания не оставляет частичных изменений проекта.

Сервис независим от Кинопоиска; доступ и квоты зависят от его условий. Приложение показывает ошибки ключа, квоты, ограничения частоты и сети, не выполняет бесконечных повторов. Ключ передаётся исключительно API; в запросах изображений его нет. Перенаправления запросов с ключом запрещены, изображения ограничены известными адресами сервиса. Ответы ограничены по размеру, кэш и cookies отключены.

`Scripts/benchmark-metadata.py` проверяет 300 циклов обработки результатов и миниатюр на фиксированных ответах API без расхода квоты. Это отдельный замер слоя метаданных, не всего интерфейса и не скорости внешнего сервиса. Живой поиск требует ключа; проверки с фикстурами не подменяют его проверку.

Проверка версии 0.5.0: [работоспособность и дистрибутив](Docs/verification-0.5.0.md), [нагрузка](Docs/performance-0.5.0.md). Отдельное тестовое окно с фиксированными ответами собирается через `python3 Scripts/build-ui-harness.py`; оно не включается в релиз и не обращается к внешнему API.
