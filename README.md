# MKVStudio 0.3.0

Нативная macOS-обёртка над **mkvmerge, mkvinfo, mkvextract и mkvpropedit** на SwiftUI. Обработка медиа выполняется внешними консольными утилитами. Приложение не декодирует и не перекодирует аудио и видео.

## Возможности

- **Сборка:** импорт видео, аудио и субтитров, перетаскивание из Finder, чтение дорожек через `mkvmerge -J`. Выбор, порядок, названия, языки, default/forced и задержка дорожек.
- **Склейка:** последовательное соединение файлов с явным сопоставлением дорожек через `--append-to` и `--append-mode file`. Порядок файлов меняется кнопками. Выбранные дорожки должны иметь одинаковый состав, порядок, кодеки и параметры. Окончательную совместимость проверяет mkvmerge. Имена и цветовые параметры результата берутся из первого файла.
- **Разбиение:** по размеру, длительности, отметкам времени, главам или диапазонам. Диапазоны с `+` соединяются в одну часть. Есть ограничение числа файлов и связывание сегментов. Результат — новая папка `имя.parts`, файлы `part-001.mkv` и далее; один выбранный фрагмент может называться `part.mkv`. Разрезы привязаны к ключевым кадрам, поэтому время и размер приблизительные.
- **Визуальные главы:** таблица, временная шкала, ползунок начала, имя, язык, начало/конец, добавление и удаление глав, вложенные главы, порядок и несколько редакций. Импорт XML/простого текста, чтение из MKV через mkvextract, экспорт XML. Сохраняются UID, флаги, дополнительные названия и прочие нетронутые XML-элементы. Главы редактора заменяют главы исходников при сборке. Сортировка глав не выполняется автоматически: порядок редакции, в том числе ordered editions, сохраняется.
- **Цвет и HDR:** PQ/HLG, основные цвета, матрица, диапазон, число бит, MaxCLL/MaxFALL, координаты RGB и белой точки, минимальная/максимальная яркость мастеринга. Пустое поле сохраняет исходное значение. Это правка метаданных контейнера, не преобразование SDR в HDR, не изменение битности кодека и не создание динамических метаданных Dolby Vision/HDR10+.
- **Вложения:** обложки, шрифты, выбор существующих вложений; сохранение тегов и исходных глав.
- **Очередь:** снимки параметров и XML глав, последовательная обработка, прогресс, отмена, ограниченный журнал, открытие результата в Finder. Ожидающие задания после перезапуска запускаются вручную.
- **Извлечение:** выбранная дорожка через mkvextract, включая сопутствующие файлы VobSub.
- **Информация:** структура контейнера через mkvinfo.
- **Заголовки:** названия, языки и флаги через mkvpropedit в отдельной копии. Состав дорожек, задержки и HDR в этом действии не меняются; для них используется сборка.
- **Проекты:** автосохранение с задержкой 400 мс, файлы `.mkvstudio`; проекты версии 0.1 продолжают открываться. Светлая, тёмная и системная темы, нативные панели и сочетания клавиш.

## Запуск и инструменты

Основной дистрибутив — `MKVStudio-0.3.0-macOS-arm64.dmg`. Откройте его и запустите **Install MKVStudio.pkg**. Установщик macOS поместит приложение в `/Applications`.

Требуются **Apple Silicon и macOS 14+**. Приложение имеет локальную ad-hoc подпись; установщик пока не подписан Developer ID Installer и не нотарифицирован Apple. При скачивании macOS может потребовать явного разрешения в «Конфиденциальность и безопасность». Защиту системы отключать не нужно.

Установщик проверяет четыре команды в `/opt/homebrew/bin`, `/usr/local/bin` и собственной папке. Если все доступны, ничего не скачивается и не заменяется. Если часть отсутствует, установщик скачивает закреплённую официальную сборку консольных утилит 102.0 (28 МБ, нужен интернет), сверяет SHA-256 и устанавливает отдельные исполняемые файлы и библиотеки в `/Library/Application Support/MKVStudio/ConsoleTools`. Только для недостающих команд создаются ссылки в `/usr/local/bin`. Существующие файлы и ссылки не перезаписываются. Графическое приложение поставщика не устанавливается и не требуется.

При ошибке сети, контрольной суммы или проверки утилит установка завершается с ошибкой. В интерфейсе используются названия консольных команд; исходное имя пакета встречается только в проверенном URL поставщика, пути внутри скачанного архива и лицензии поставщика.

В настройках можно выбрать отдельный исполняемый файл для каждой утилиты. Явные пользовательские пути имеют приоритет. Альтернативный ZIP содержит только приложение: `build/MKVStudio-0.3.0-macOS-arm64.zip`.

Справочники: [mkvmerge](https://man.archlinux.org/man/mkvmerge.1.en), [mkvextract](https://man.archlinux.org/man/mkvextract.1.en), [mkvinfo](https://man.archlinux.org/man/mkvinfo.1.en), [mkvpropedit](https://man.archlinux.org/man/mkvpropedit.1.en).

## Сохранность данных

Исходники не перезаписываются. Обработка идёт в уникальной временной папке рядом с назначением. Файл или папка с частями переносится на конечное место только при коде завершения 0 или 1 (предупреждение консольной утилиты). Существующий результат не заменяется, включая появление файла во время обработки. При отмене временные данные задания удаляются. После аварийного закрытия путь к оставшейся папке указан в журнале.

Утилиты запускаются через `Process` с массивом аргументов, без shell. Для Unicode-путей используется UTF-8. Проект и история хранятся локально; сетевых функций в приложении нет. Большие медиафайлы не загружаются в память приложения.

## Проверки и сборка

```sh
bash Scripts/build-app.sh
bash Scripts/build-dmg.sh
python3 Scripts/check-engine.py
python3 Scripts/benchmark.py
```

Сборка создаёт приложение, ZIP и SHA-256 в `build/`. Этот путь работает с Command Line Tools; полный Xcode не требуется. Проект `MKVStudio.xcodeproj` также обновлён. В полном Xcode тесты Swift Testing запускаются через `bash Scripts/test.sh`.

В установленном здесь Command Line Tools отсутствует модуль `Testing`. Скрипт `check-engine.py` выполняет те же **15 интеграционных сценариев** из `Tests/EngineTests.swift` с обычными проверочными функциями. Используются настоящие консольные утилиты. Проверяются потоки и вложения побайтово, склейка, все режимы разбиения, главы и вложенность, HDR, независимые пути инструментов, старые проекты, защита исходников/результата, Unicode, большой вывод и отмена.

`Scripts/benchmark.py` создаёт временный синтетический PCM-файл 1 ГиБ, выполняет 12 операций через настоящий `AppState` и удаляет результаты. Измеряет CPU отдельно для обёртки и утилит, RSS каждые 50 мс. Интерфейс измеряется отдельно через `Scripts/sample-ui.py`. Результаты версии 0.3.0 — в [отчёте о нагрузке](Docs/performance-0.3.0.md).

Шаблон GitHub Actions рассчитан на самостоятельно подключённый macOS ARM64 runner с четырьмя установленными консольными утилитами. Удалённый CI в рамках этой работы не запускался.

## Интерфейс 0.3.0

Боковая панель открывается с шириной 300 pt, инспектор — 380 pt (максимумы их диапазонов); разделители остаются изменяемыми. Во всех рабочих разделах используется общая широкая зелёная кнопка «Добавить в очередь». Красная кнопка «Убрать завершённые» закреплена внизу очереди и остаётся видимой при открытом журнале и пустом списке. Она очищает историю, не файлы результатов. Настройки занимают 700 × 650 pt и не содержат вертикальной прокрутки.

Стандартные `NavigationSplitView`, `Table`, `inspector`, системные кнопки, панели и материалы. Ориентир — [принципы Apple](https://developer.apple.com/design/human-interface-guidelines/design-principles).

## Проверка установщика

`Scripts/test-installer.py /путь/к/официальному-образу.dmg` проверяет чистую и частичную установку, независимый запуск утилит, повторный запуск, повреждённую загрузку и конфликты ссылок в изолированных временных папках. Системные команды не изменяются. URL и SHA-256 закреплены в `Installer/scripts/install-console-tools.sh`.

Для проверки дистрибутива применяются `hdiutil verify`, `pkgutil --expand-full`, проверка подписи извлечённого приложения и сравнение исполняемого файла с исходной сборкой. Шаг ввода администраторского пароля выполняется самим пользователем в системном Установщике.
