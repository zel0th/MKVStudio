# Проверочные файлы

`Видео.mp4` — маленький видеообразец из Homebrew (`test/support/fixtures/test.mp4`); лицензия Homebrew приложена.

Остальные данные тесты создают самостоятельно во временных папках: синтетический PCM, субтитры, обложки,
главы и результаты сборки. Пользовательские фильмы, рабочие проекты и локальные пути в репозиторий не включены.
